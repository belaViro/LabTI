## 简介

**SciTI（科研TI）** 是一个面向学术圈的娱乐向人格测试，灵感源自 MBTI，但彻底重构了维度体系与价值取向。它通过 16 道科研日常情景题，从 **信仰、权力、技能、生存** 四个维度对测试者进行"诊断"，最终归入 16 种（+1 隐藏）科研人格之一。

核心目的不是"认识自我"，而是**用黑色幽默的方式，揭示当代学术界结构性荒诞**——让科研工作者在苦笑中获得共鸣，在共鸣中看见系统性困境。

---

## ✨ 功能特点

- **🧬 16+1 种科研人格** —— 从"核动力驴"到"学术幽灵人口"，每种都有独立档案
- **🎨 MBTI 风格分享海报** —— 每型专属配色，一键生成朋友圈卡片
- **📊 四维光谱 + 雷达图** —— 可视化你的学术人设
- **🥚 隐藏彩蛋** —— 乱点触发"审稿人2号"特殊人格
- **📱 纯前端，零依赖** —— 无需服务器，无需数据库，双击即用

## 🚀 快速开始

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/yourname/sciti.git

# 进入目录
cd sciti

# 直接用浏览器打开
open index.html        # macOS
start index.html       # Windows
```

或直接把 `index.html` 拖到浏览器里。

### 文件结构

```
sciti/
├── index.html          # 入口文件
├── css/
│   └── style.css       # 样式（伪学术档案风）
├── js/
│   └── script.js       # 题库、结果库、计分逻辑、海报生成
├── README.md           # 本文件
└── docs/
    └── 科研TI.md        # 策划文档（含16型完整档案）
```
